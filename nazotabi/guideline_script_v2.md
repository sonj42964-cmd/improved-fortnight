# ナゾたび 대본 지침서

> 채널명: ナゾたび
> 목적: 세계의 수수께끼와 신기한 잡학을 확인된 사실로 풀어 주는 지식 채널 전용 대본 지침서
> 핵심 목표: 높은 시청지속률 · 사실 기반 정확성 · 채널 고유 개성 · YouTube 정책 저위험 · 구독 전환 · 댓글 참여

## 채널 설정 (이 지침서를 적용하는 채널)

- 채널명: ナゾたび
- 채널 형식: 세계의 수수께끼와 신기한 잡학을 이야기처럼 풀어 주는 지식 채널 (여행·유적, 동물, 쇼와 생활, 철도·탈것, 음식의 역사)
- 초고 언어: 한국어로 먼저 작성 → 완성 후 일본어 번역 (정중체, 원어민 감수 권장)
- 고정 클로징: **"ナゾたび였습니다"** (일본어 번역: 「ナゾたびでした。」)
- 주 시청자: 일본의 50~70대 남성 (TV 시청 약 30%)

## 0. 최상위 원칙

아래 원칙은 다른 모든 조항보다 우선한다.

1. **사실로 확인된 내용만 확정형으로 작성한다.**
2. **확인되지 않은 수치·발언·인물의 경력·사례는 쓰지 않는다.**
3. **특정 민족·국가·종교·정치 집단에 대한 우열 판단이나 선동적 결론을 내리지 않는다.**
4. **제목과 썸네일이 약속한 내용을 첫 30초부터 실제로 제공한다.**
5. **인트로 첫 문장은 제목의 핵심 사건·모순·위기와 직접 연결되는 궁금증 유발 문장이다 (PART 4-0).**
6. **사실, 해석, 통설, 가정, 사례를 명확히 구분한다.**
7. **하나의 사건에 대해 다른 해석이나 반론이 존재하면 함께 제시한다.**
8. **매 영상의 핵심 질문·자료·논리·결론이 실질적으로 달라야 한다.**

### 0-1. 규칙 충돌 우선순위

규칙이 충돌하면 다음 순서로 적용한다.

1. 사실 검증과 시청자 오인 방지
2. YouTube 정책 위험 최소화
3. 제목·썸네일·본문의 일치
4. 서사의 논리적 완결성
5. 자연스러운 발화와 시청지속률
6. 구독 전환·댓글 참여 장치 (PART 14)
7. 분량과 형식

### 0-2. 제목 위험 요소 확인 절차

제목에 다음 요소가 있다면 리서치 전에 사용자에게 알리고 진행 여부를 확인한다.

- 특정 민족·국가·종교 집단에 대한 우열·비하·선동으로 해석될 수 있는 표현
- 현대 소수민족 관련 역사 소재
- 사실관계가 불확실하거나 극단적으로 논쟁적인 사건
- 과장·허위로 보이는 수치나 단정 표현

## PART 1. 채널 정체성과 화자 규정

### 1-1. 채널 형식

> 공식 기록·연구 논문·기관 자료를 따라 수수께끼의 배경, 전개, 결과를 추적하는 지식 다큐멘터리.
> 화자는 사실을 연결하고, 서로 다른 해석을 비교하고, 왜 그렇게 전개됐는지 설명한다.

### 1-2. 화자 규정

기본 서술은 3인칭이되, 채널 고유 개성을 살린 구어체 억양을 적극 허용한다.

**허용하는 것**
- `~죠`, `~거든요`, `~던 겁니다`, `~인데요` 등 구어체 어미
- 무거운 정보 직후 현대어 유머 환기 (사실 왜곡 없이)
- 제한적 시청자 호명 (`여러분`은 본문 중반·결말에서만, 남발 금지. 전환·참여 장치 문장도 같은 규칙을 따른다)
- 채널 클로징: **"ナゾたび였습니다"** (매 영상 고정, 일본어 번역은 「ナゾたびでした。」)
- 역사 용어 직후 즉시 구어체 재번역 (PART 5 참조)

**금지하는 것**
- 화자의 이름·직함·전공·경력 부여
- `저는 이렇게 생각합니다` 류의 개인 견해 표명
- `제가 직접 현장에 가 보니` 류의 개인 경험 서술
- 특정 민족·국가에 대한 개인 호오 표명

### 1-3. 클로징 공식

모든 영상은 다음 구조로 마무리한다.

```
[보편적 메시지 or 후대에 미친 영향 1~2문장]
[다음 편 예고 + 구독 연결 — PART 14-4]
[댓글 질문 1개 — PART 14-3]
"ナゾたび였습니다"
```

## PART 2. 정책 저위험 원칙

### 2-1. 단정·선동 표현 금지

| 지양 표현 | 권장 표현 |
|---|---|
| 이 민족은 원래 호전적이다 | 당시 이 지역의 정치 구조가 잦은 군사 충돌로 이어졌습니다 |
| 이 나라가 무조건 옳았다 | 이 결정에 대해서는 지금도 평가가 갈립니다 |
| 이건 명백한 음모입니다 | 여러 해석이 제기되는데, 확인된 사료로는 여기까지입니다 |

### 2-2. 해석과 평가의 한계

```
이 전투는 후대 역사가들 사이에서도 평가가 갈립니다.
다만 확인 가능한 사료를 기준으로 전개 과정을 살펴보면 다음과 같습니다.
```

### 2-3. 고위험 소재 특별 취급

다음 소재는 PART 0-2의 사전 확인 절차를 반드시 거친다.

- 현대까지 이어지는 소수민족·원주민 관련 역사
- 현재진행형 영토·국경 분쟁과 직결된 역사
- 특정 종교의 기원이나 교리에 대한 비판적 서술
- 홀로코스트를 비롯한 20세기 대량학살
- 현대 국가 간 과거사 갈등

## PART 3. 리서치와 사실 검증

### 3-1. 사실성 기준

- 검증된 사실만 확정형으로 작성
- 추정은 추정이라고 표시
- 역사적 평가는 사실과 분리해서 표시
- 인과관계가 확인되지 않으면 원인으로 단정하지 않음
- 사료마다 수치가 다르면 그 차이를 설명

### 3-2. 출처 우선순위

**1순위 — 원사료·공식 자료**
공식 기록물(실록·관보·공문서), 발굴 유물과 고고학 보고서, 당대 문헌과 비문, 국가기관·박물관·기록보존소 자료, 기관·기업·단체의 공식 발표와 통계 (예: 철도 회사, 관공서, 연구소)

**2순위 — 검증 연구**
피어리뷰 학술논문 (동물·과학·공학 분야 포함), 대학·국책 연구기관의 연구, 방법론과 원자료가 공개된 연구서

**3순위 — 보조 자료**
전문 다큐멘터리·박물관 전시 자료, 해당 분야 전문가의 저서, 원문 취재가 확인되는 언론 보도

### 3-3. 불인정 출처

- 출처 불명 커뮤니티나 위키류의 무검증 인용
- 개인 블로그의 재인용
- 출처가 생략된 AI 답변
- 검증되지 않은 유사역사학·음모론 사이트

### 3-4. 사실·해석·평가의 문장 구분

**확인된 사실**
```
사료에 따르면 이 시점에 병력이 이동한 기록이 남아 있습니다.
```

**해석**
```
이 기록은 당시 지휘부의 판단이 급박했음을 보여줍니다.
```

**가능성**
```
다만 현재 남은 사료만으로는 정확한 의도까지 단정하기는 어렵습니다.
```

**출처 충돌**
```
두 기록은 병력 규모에서 차이를 보이는데, 편찬 시점과 목적이 다르기 때문입니다.
```

## PART 4. 인트로 유형 — 4가지 로테이션

### 4-0. 공통 규칙 — 첫 문장은 궁금증 유발 문장

**어떤 유형(A·B·C·D)으로 시작하든, 인트로의 첫 문장은 궁금증을 일으키는 문장이어야 한다.**

**궁금증 유발 문장의 조건 (하나 이상 충족)**
- 의문형이다 ("~일까요", "~했을까요")
- 정보 공백이 있다 (결과·이유·정체를 일부러 숨긴다)
- 모순이 있다 (서로 어긋나는 사실을 나란히 놓는다)

**기준**
- 첫 문장만 들어도 "그래서?" 하고 다음 문장을 듣고 싶어져야 한다
- 제목의 핵심 사건·모순·위기와 직접 연결한다 (PART 0-5)
- 영상 안에서 반드시 풀리는 궁금증이어야 한다 (낚시 금지, PART 0-4)
- 인사말·설명문·연대기 나열로 시작하지 않는다

**유형별 적용**

| 유형 | 첫 문장 만드는 법 |
|---|---|
| A형 | 격언을 말하면서 곧바로 의문으로 비튼다 (한 문장 안에서) |
| B형 | 익숙한 현재 상황을 말하면서 의문을 함께 던진다 |
| C형 | 숫자를 던지고 곧바로 "이게 얼마나 큰 숫자일까요" 식의 의문을 붙인다 |
| D형 | 제목의 핵심 의문을 그대로 던진다 |

### 4-1. 핵심 원칙

**직전 영상과 같은 유형을 절대 반복하지 않는다.**
유형은 그 영상 주제의 핵심 긴장이 자동으로 결정한다.

### 4-2. 유형 자동 판단 루틴

```
주제의 핵심 긴장이...

① 규모·수치가 충격적         → C형 (숫자 충격)
② 역설·배신·통념과 반대      → A형 (속담/격언 비틀기)
③ 현재 상황과 연결 가능      → B형 (시사 공감)
④ 원인·이유가 의문           → D형 (질문 직격)

+ 직전 영상 유형과 겹치면 → 차선 유형 선택
```

### 4-3. 4가지 유형 상세

**A형 — 속담/격언 비틀기**
- 방식: 익숙한 격언이나 통념을 제시하고 즉시 비틀기
- 효과: 시청자가 "맞아" 하고 동의한 직후 반전
- 예시:
```
"원수는 외나무다리에서 만난다는데, 이 두 나라는 어디서 마주쳤을까요.
외나무다리도 아닌,
서로가 만든 조약문 위에서였습니다.
그리고 거기서부터 모든 것이 틀어지기 시작했죠."
```

**B형 — 시사 공감 → 거리 좁히기**
- 방식: 현재 일어나고 있는 일이나 익숙한 감각을 먼저 제시하고, 역사적 사건과 연결
- 효과: "나랑 관계있는 이야기구나"라는 감각
- 예시:
```
"전쟁이 생중계되는 시대, 80년 전 사람들은 전황을 어떻게 알았을까요.
지금은 스마트폰 하나면 지구 반대편 전선이 실시간으로 올라오죠.
그런데 이 시대 사람들도 라디오 앞에 모여
똑같이 전황을 들으며 떨었습니다."
```

**C형 — 숫자 충격 → 감정 장면**
- 방식: 규모를 보여주는 수치를 먼저 던지고, 그 수치를 인간적 감각으로 전환
- 효과: 숫자가 추상으로 끝나지 않고 현실 무게로 전달됨
- 예시:
```
"사상자 5천만, 이게 얼마나 큰 숫자일까요.
전쟁이 끝나고 나서야 집계된 숫자인데요.
지금 한국 인구 전체가 두 번 사라지는 규모입니다."
```

**D형 — 질문 직격**
- 방식: 제목의 핵심 의문을 첫 문장부터 직접 던지기
- 효과: 시청자가 즉시 "나도 그게 궁금한데"로 진입
- 예시:
```
"대체 왜 이 나라는 이기고도 졌을까요.
병력도 많고, 보급도 충분했습니다.
그런데 결과는 완전히 달랐죠."
```

### 4-4. 인트로 구조 (유형 결정 후)

1. 유형에 맞되 궁금증 유발 문장으로 시작하는 첫 문장 (PART 4-0, 즉시 투척, 인사말 절대 금지)
2. 이해관계 확장 (왜 중요한 사건인지)
3. 신뢰 앵커 숫자 (구체적 수치 1~2개)
4. 핵심 질문 제시
5. 전개 예고 (선택적)

**분량: 200~350자 / 발화 약 12~25초**

**절대 금지**
- `안녕하세요`로 시작
- 채널명·화자 소개
- 영상 목차 전체 낭독
- 근거 없는 충격 수치

## PART 5. 구어체 번역 원칙

### 5-1. 핵심 규칙

**역사 용어를 쓰더라도 즉시 구어체로 재번역한다. 시청자가 혼자 해석하게 두지 않는다.**

| 역사 표현 | 구어체 번역 예시 |
|---|---|
| 대규모 포위 섬멸전 성공 | "완전히 쌈싸먹은 겁니다" |
| 전략적 실패 | "그냥 물 주먹이었던 거죠" |
| 불가침조약 파기 우려 | "언제 뒤통수 칠지 모르는 상황" |
| 권력 집중 완성 | "이 나라가 곧 이 사람, 이 사람이 곧 이 나라가 돼버린 겁니다" |
| 전선 붕괴 | "하루아침에 다 날아간 거예요" |

### 5-2. 번역 원칙

- 어려운 용어를 쓴 직후 바로 쉬운 말로 한 번 더 설명
- 비유는 이해를 높일 때만, 억지로 넣지 않음
- 같은 비유를 여러 영상에서 반복하지 않음
- 비유 뒤에는 실제 사실관계를 다시 연결

### 5-3. 문장 호흡

**짧은 문장** — 전환, 반전, 핵심 사실, 다음 질문
**중간 문장** — 하나의 사실과 의미 전달
**긴 문장** — 원인과 결과 연결, 배경·구조 해설

**리듬 기본 패턴**
```
짧은 문장(훅) → 긴 문장(조건·갈등 확장) → 짧은 문장(반전) → 중간 문장(도착지 제시)
```

**어미 변주**
- `~습니다`·`~입니다` 계열과 `~죠`·`~인데요`·`~거든요` 계열을 자유롭게 섞는다
- 동일 어미를 연속 3문장 이상 반복하지 않는다
- 사실·수치는 `~습니다`로, 흐름 전환·반전 직전은 구어체 어미로

## PART 6. "인정 → 반전" 서사 구조

### 6-1. 핵심 원칙

**모든 섹션은 이 패턴을 기본으로 한다.**

```
뭔가 맞는 말 (인정·동의)
→ "하지만" / "근데" / "그런데"
→ 뒤집기 (반전·의심·새로운 사실)
→ 몰입
```

시청자를 **동의 → 의심 → 몰입** 사이클로 반복해서 돌리는 것이 시청지속률의 핵심 장치다.

### 6-2. 실제 적용 예시

```
"이 시점까지만 보면 전황은 완전히 한쪽으로 기울어 보입니다.
누가 봐도 이미 결정된 것 같았죠.
그런데 실제 사료를 보면 이야기가 달라집니다."
```

```
"당시 지휘부 입장에서는 이 선택이 합리적이었습니다.
보급선이 살아있고, 병력도 충분했으니까요.
하지만 그 판단이 틀렸다는 게 불과 사흘 만에 드러납니다."
```

### 6-3. 정보 긴장도 곡선

```
위기·모순 즉시 제시
→ 배경 설명
→ 균열 (통설이 깨지는 지점)
→ 원인 추적
→ 반전·다른 해석
→ 결정적 국면
→ 결론 회수
```

### 6-4. 중반 이탈 방어

영상의 45~60% 지점에는 반드시 새로운 가치가 있어야 한다.

- 앞선 흐름을 뒤집는 반전
- 사료 간 기록의 차이
- 예상 밖의 인물이나 변수 등장
- 다른 진영·다른 시점에서 본 같은 사건

## PART 7. 유머 삽입 원칙

### 7-1. 타이밍 규칙

**유머는 항상 무거운 정보 직후에 삽입한다.**

```
[무거운 사실 설명]
→ [현대어 유머 1문장으로 환기]
→ [다음 정보로 자연스럽게 전환]
```

### 7-2. 목적

- 정보 폭탄 직후 시청자에게 숨 고를 공간 제공
- 핵심 내용이 기억에 박히게 하는 장치
- 다음 정보를 받아들일 준비 상태로 전환

### 7-3. 적용 예시

```
(대규모 포위 성공 설명 후)
"상대 입장에서는 최악 중의 최악인 상황이었죠."
```

```
(동맹국의 실패 설명 후)
"도와주러 왔다가 오히려 짐이 돼버린 겁니다."
```

### 7-4. 유머 기준

- 사실관계를 왜곡하지 않는다
- 특정 민족·국가를 비하하는 방식이 아닌, 상황 자체의 아이러니를 활용한다
- 억지로 넣지 않는다 — 자연스럽지 않으면 건너뛴다

## PART 8. 본문 설계

### 8-1. 전체 길이

| 구간 | 분량 |
|---|---|
| 인트로 | 200~350자 |
| 본문 (1부~8부) | 6,400~8,000자 (부당 800~1,000자) |
| 결말 | 350~500자 |
| **전체 총량** | **6,950~8,850자** |

결정적 국면·반전 파트는 최대 1,200자까지 확장 가능. 단 전체 합계는 범위 안에서.

### 8-2. 본문 단위

본문은 8개 의미 단위(8부)로 구성한다.

각 단위에는 다음 중 최소 세 가지 포함:
- 새로운 질문
- 확인된 사실
- 배경이나 구조 설명
- 비교 자료
- 다른 해석이나 반론
- 사례 또는 구체적 장면
- 조건과 한계
- 다음 단위로 넘어갈 이유

**사실-의미 연결 원칙**
사실이나 수치를 제시한 문단은 그 문단 안에서 반드시 "이것이 사건의 흐름에 어떤 의미인가"로 이어져야 한다. 사실 나열만 하고 다음으로 넘어가지 않는다.

### 8-3. 본문 서사 유형 선택

주제에 따라 하나를 선택한다.

- **위기 극복형**: 위기 고조 → 최악의 순간 → 반전의 계기 → 역전 → 결말
- **원인 추적형**: 사건 → 원인 후보 → 사료 검증 → 후보 제거 → 핵심 원인
- **인물 재평가형**: 통념 속 이미지 → 실제 기록과의 괴리 → 배경 → 재평가
- **구조 해설형**: 문제 상황 → 제도·체제의 목적 → 실제 작동 방식 → 결과
- **사료 검증형**: 널리 알려진 이야기 → 원사료 확인 → 기록 간 차이 → 수정된 결론

### 8-4. 구조 자기참조 금지

대본 본문은 자신의 구조를 인식하는 문장을 포함하지 않는다.

**금지**
```
4부에서 말씀드린 것처럼 / 아까 인트로에서 말씀드린 것처럼
```

**대체 — 내용을 직접 재언급**
```
앞서 확인한 5,600명이라는 전사자 수는 / 전선이 하루가 다르게 밀리던 이 시기에
```

## PART 9. 시리즈 연결 전략

### 9-1. 핵심 원칙

시리즈 연결은 광고처럼 별도로 붙이지 않는다. **대본 안에 자연스럽게 심는다.**

```
앞 영상 → 현재 영상 → 다음 영상
```

이 흐름을 시청자가 이탈할 틈 없이 이어지게 만든다.

### 9-2. 연결 삽입 위치

- **앞 영상 연결**: 본문 초반부 — 이미 알고 있는 시청자와 새로 온 시청자 모두 자연스럽게 진입하게
- **다음 영상 예고**: 결말 직전 — 클로징 바로 앞. 구독 연결 문장은 여기에 함께 둔다 (PART 14-4)

### 9-3. 연결 표현 예시

**앞 영상 연결 (선택적)**
```
"지난 영상에서 이 전쟁이 시작된 배경을 살펴봤는데요.
오늘은 그 흐름이 어떻게 뒤집어졌는지를 따라가 봅니다."
```

**다음 영상 예고 (선택적)**
```
"이 사건 이후 어떻게 흘러갔는지는 다음 영상에서 이어집니다."
```

## PART 12. 썸네일 후킹 문구

### 12-1. 작동 시점

리서치 완료 직후, 인트로 작성 전에 3세트 제시한다.

### 12-2. 문구 구조

- 1세트 = 첫줄 + 둘째줄 (2줄이 한 세트)
- 총 3세트 제공
- 패턴 A (사건·수치 + 질문)와 패턴 B (상황 + 이유)를 항상 혼합
- **각 줄은 8~14자 내외로 짧게 쓴다 — 한 호흡에 읽히는 길이를 넘지 않는다**
- **두 줄 중 최소 한 줄은 의문형·정보 공백·반전 예고 중 하나로 끝나 궁금증을 유발한다**
- **첫줄에서 상황을 전부 설명하지 않는다 — 둘째줄까지 읽어야 궁금증이 완성되도록 정보를 나눠 배치한다**
- 완결된 설명문이 아니라 압축된 구(句) 형태를 우선한다
- 둘째줄에서 답을 다 주지 않는다 — 본문을 봐야 풀리는 긴장을 남긴다

**패턴 A**
```
첫줄: 병력 3배 차이
둘째줄: 그런데 이겼다
```

**패턴 B**
```
첫줄: 하루 만에 무너진 방어선
둘째줄: 진짜 이유는 따로 있다
```

### 12-3. 문구 기준

- 제목 + 리서치 내용에 직접 관련된 문구만 사용
- 자극적·허위·비하 표현 금지
- 영상에 실제로 없는 내용을 낚시로 넣지 않음
- 길고 설명적인 문장형 문구 금지 — 짧고 압축된 구 형태만 사용
- 궁금증 없이 결론·정보를 전부 공개하는 문구 금지

### 12-4. 출력 양식

```
[세트 1]
첫줄:
둘째줄:

[세트 2]
첫줄:
둘째줄:

[세트 3]
첫줄:
둘째줄:
```

### 12-5. 제목-썸네일-인트로 일치 원칙

썸네일 후킹 문구에서 약속한 내용은 반드시 인트로에 포함되어야 한다. 썸네일의 핵심 후킹 요소가 본문 중후반에서만 등장하는 것은 개선이 필요한 사례다.

## PART 14. 댓글 유도와 구독 전환 장치

### 14-1. 핵심 원칙

- 전환·참여 장치는 광고처럼 붙이지 않고, **시청자가 얻는 가치(다음 편, 이어지는 이야기, 같은 시리즈)** 에 연결한다.
- 영상당 **구독 안내는 최대 2회**(본문 중반 1회 + 결말 1회), **댓글 질문은 결말에 1개**를 기본으로 한다.
- **인트로와 본문 초반 30초에는 구독·댓글 요청을 넣지 않는다.** 첫 30초는 제목과 썸네일이 약속한 내용을 제공하는 데 쓴다 (PART 0-4).
- 전환·참여 문장 전체 분량은 **300자 이내**로 하고, 본문·결말 분량 범위 안에 포함한다.
- 사실 정확성과 정책 위험 최소화보다 앞서지 않는다 (PART 0-1).

**금지**
- 보상 약속 ("구독하면 ~를 드립니다")
- 압박·공포·가짜 긴급성 ("지금 안 누르면 다시는 볼 수 없습니다")
- 영상 내용과 무관한 구독 호소
- 사실을 부풀리거나 숨겨서 댓글을 유도하는 문장
- 정치·종교·민족 논쟁을 일으킬 수 있는 질문
- 개인정보나 연락처를 묻는 질문
- 외부 링크·유료 콘텐츠 유도 (PART 10-3)
- 구독·좋아요 교환, 구독자 수 조작 유도

### 14-2. 삽입 위치와 분량

| 위치 | 장치 | 분량 |
|---|---|---|
| 인트로·본문 초반 30초 | 넣지 않는다 | 0자 |
| 본문 중반 (4부 끝~5부 초반) | 중간 구독 연결 1회 | 40~80자 |
| 본문 후반 (선택) | 시청자 경험·선택 질문 1회 | 40~80자 |
| 결말 직전 | 다음 편 예고 + 구독 연결 | 60~120자 |
| 결말 마지막 줄 | 댓글 질문 1개 (경험형 기본, PART 14-3) | 30~70자 |

중간 구독 연결은 **한 가지 의문이 풀려 시청자가 만족한 직후, 다음 질문으로 넘어가기 직전**에 둔다. 열린 질문 한가운데에는 넣지 않는다.

### 14-3. 댓글 질문 설계

**기본 원칙: 결말의 댓글 질문은 시청자가 자기 경험을 떠올리게 하는 경험형 질문으로 한다.**

**조건**
- 한 가지만 묻는다
- 정답이 없고, 쉽게 답할 수 있다
- 시청자가 자기 경험·기억을 떠올려 답할 수 있다
- 한 장면·한 시점을 떠올리게 한다 ("처음", "어릴 때", "가 본 곳", "직접 본")
- 영상 소재와 직접 연결된다
- 사실 확인이 필요 없고, 민감 소재를 건드리지 않는다

**유형**

| 유형 | 방식 | 예시 |
|---|---|---|
| 경험형 (기본) | 시청자가 자기 경험·기억을 떠올리게 한다 | "여러분 동네에는 이런 이야기가 전해 내려오나요." |
| 선택형 | A/B 중 선택 | "보급선과 병력 중 어느 쪽을 먼저 지키셨을까요." |
| 예측형 | 다음 편 궁금증 | "다음 편에서 이 문제의 결말을 다루는데, 어떻게 풀렸을 것 같으세요." |
| 제안형 | 다음 소재 제안 | "다음에 다룰 소재는 댓글에 제안해 주세요." |

결말 댓글 질문은 경험형을 우선하고, 선택형·예측형·제안형은 보조로 쓰거나 본문 후반 질문에 쓴다. 경험형과 다른 유형을 한 문장에 섞어도 된다.

**경험형 질문 만드는 법**
- 영상 소재와 이어지는 **개인적인 장면 하나**를 고른다 (처음 겪은 일, 어릴 때 기억, 직접 가 본 곳, 직접 본 것)
- 정답을 요구하지 않고 **추억과 기억**을 말할 수 있게 한다
- 쉬운 한 문장으로 묻는다

**분야별 경험형 질문 예시**

| 분야 | 예시 |
|---|---|
| 여행·유적 | "여러분이 직접 가 본 곳 중에 가장 신기했던 유적은 어디였나요." |
| 동물 | "여러분이 직접 본 동물의 신기한 행동이 있나요." |
| 쇼와 생활·물건 | "여러분 집에 처음 들어온 전화기는 어떤 모양이었나요." |
| 철도·탈것 | "처음 신칸센을 탔던 날을 기억하시나요." |
| 음식 | "어릴 때 먹던 주먹밥에는 어떤 속이 들어 있었나요." |

**금지 질문**
- "어떻게 생각하세요?"처럼 막연한 질문
- 두 개 이상을 한꺼번에 묻는 질문
- 정답을 맞히는 퀴즈 형태
- 편을 가르거나 비난을 부르는 질문
- 건강·가족사·재산 등 민감한 개인사를 캐묻는 질문

### 14-4. 구독 연결 문장 설계

**유형**
- 가치 연결형: 다음 이야기와 잇는다
- 시리즈형: 같은 주제를 이어서 다룬다고 알린다
- 예고형: 다음 편의 궁금증을 남긴다

**예시**
```
이 이야기의 뒷부분은 다음 영상에서 이어집니다.
채널 등록을 해 두시면 놓치지 않고 보실 수 있습니다.
```
```
이런 이야기를 시리즈로 이어서 다루고 있는데요.
궁금하시다면 채널 등록을 해 두시면 됩니다.
```

**규칙**
- 가치를 먼저 말하고, 요청은 한 줄로 짧게 한다
- 존댓말을 유지하고 압박하지 않는다
- 한 영상 안의 구독 안내 두 문장은 서로 다르게 쓴다
- 같은 문장을 여러 영상에서 반복하지 않는다 (PART 5-2의 비유 반복 금지와 같은 취지)
- 결말의 구독 연결 문장에는 채널명을 한 번 넣어 이름을 기억하게 한다 (예: "ナゾたび 채널 등록을 해 두시면 놓치지 않고 보실 수 있습니다.")

### 14-5. 대본 밖 전환 장치 (제작 메모)

대본(발화 텍스트)에는 연출 지시를 쓰지 않는다 (PART 13). 아래 항목은 **제작 메모**로 대본 코드블록 밖에 별도 출력한다.

- **엔딩 화면**: 마지막 20초에 구독 버튼과 같은 시리즈의 다음 영상을 배치한다. 결말 마지막 문장 뒤에 20초 여백을 확보한다
- **고정 댓글**: 댓글 질문을 다시 올리고 다음 영상 링크를 넣는다
- **설명란**: 핵심 요약 1~2줄 / 참고 출처 (PART 3 기준) / 다음 영상 / 재생목록 / 구독 안내 1줄 / 댓글 질문 재게시
- **재생목록**: 시리즈 이름을 정하고 영상을 배치한다

**제작 메모 템플릿**
```
[엔딩 화면] 마지막 20초: 구독 버튼 + 다음 영상(영상명)
[고정 댓글] (댓글 질문) / 다음 영상: (링크)
[설명란] 요약 / 출처 / 다음 영상 / 재생목록 / 구독 안내 / 댓글 질문
[재생목록] (시리즈명)
```

### 14-6. 점검 체크리스트

- [ ] 첫 30초에 구독·댓글 요청이 없다
- [ ] 구독 안내가 2회 이하이고 문장이 서로 다르다
- [ ] 댓글 질문이 1개이고 14-3의 조건을 충족한다
- [ ] 결말 댓글 질문이 시청자 자신의 경험을 떠올리게 한다
- [ ] 금지 표현(14-1)이 없다
- [ ] 전환·참여 문장이 300자 이내다
- [ ] 제작 메모(엔딩 화면·고정 댓글·설명란)를 별도로 제공했다
